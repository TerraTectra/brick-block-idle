# Брик Блок Idle

Бесплатное игровое превью TerraTectra: шары разрушают блоки, осколки идут на улучшения, эволюции меняют специализацию шаров, а сингулярность открывает мета-прокачку.

[Играть в браузере](https://terratectra.github.io/brick-block-idle/) · [Скачать для игры без интернета](https://terratectra.github.io/brick-block-idle/downloads/Brick-Block-Idle-preview.zip) · [Пост и отзывы на Boosty](https://boosty.to/albertoanastazia/posts/2dcf670c-d5fb-459e-846c-62c99244a6d1)

Распакуйте архив и откройте `Brick-Block-Idle.html` в Edge или Chrome. Установка и сервер не нужны. Прогресс хранится в браузере; сохраняйте путь к файлу и не очищайте данные браузера. Веб-версия и локальный файл имеют отдельные сохранения.

В упаковке от 03.10.2026 добавлены инструкция и подтверждение перед сбросом забега. База игры — v0.11.5. Формат сохранения и экономика не менялись. Основные действия проверены в отдельном браузере без интернета, включая перезагрузку, эволюцию и отмену сброса; для части сценариев использовалось подготовленное сохранение. Полное прохождение, поздние боссы и длительный баланс ещё требуют проверки.

Игру можно скачать бесплатно. Подписка [на Boosty](https://boosty.to/albertoanastazia) поддерживает разработку и открывает материалы о её ходе.

GitHub Pages публикует корень ветки `main`; отдельная сборка Vite для текущей статической версии не требуется.
